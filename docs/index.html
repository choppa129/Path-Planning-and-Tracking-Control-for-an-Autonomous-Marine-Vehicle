How it works

The planner samples a target, finds the nearest tree node, extends by a fixed step, and rejects edges that collide with inflated circular obstacles. It limits turning at each expansion and optionally samples toward the goal. Once a route is found, standard line-of-sight pruning removes intermediate waypoints using collision checks, while angle-constrained pruning also verifies the turn at both ends of each shortcut. A feasible path is not guaranteed for every configuration.

Interact: Drag the green start or red goal marker to try a different route. The canvas uses illustrative map coordinates (pixels), not geographic coordinates. A fixed clearance of 12 pixels is added to obstacles.

Provenance: This is a new browser reimplementation of concepts from the team's original Python RRT planner and project report, not the original simulator, a synchronized vessel trial, or measured navigation performance. Randomized results may vary. Read the project report ↗
